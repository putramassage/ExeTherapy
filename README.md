# DoRehab ID — Portal Rehabilitasi & Cedera Olahraga

Website statis berbasis **HTML**, **CSS**, dan **JSON** (`index.html`, `style.css`, `data.json`) untuk mahasiswa ilmu keolahragaan, dosen, fisioterapis, dan atlet.

## Cara Upload ke GitHub & Mengaktifkannya Online (GitHub Pages)

1. Buat repositori baru di **GitHub** (misalnya `dorehab-id`).
2. Unggah isi folder `dorehab-github` ke repositori tersebut:
   - `index.html`
   - `style.css`
   - `data.json`
   - `README.md`
3. Buka tab **Settings** pada repositori di GitHub, pilih **Pages** di menu kiri.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**, arahkan ke branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu beberapa saat hingga tautan GitHub Pages (`https://<username-github>.github.io/dorehab-id/`) aktif dan dapat diakses secara online.
